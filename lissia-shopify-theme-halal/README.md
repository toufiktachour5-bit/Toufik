## 📦 Installation sur Shopify

### Étape 1 : Télécharger le thème
1. Téléchargez ce dossier en ZIP

### Étape 2 : Accéder à votre boutique Shopify
1. Connectez-vous à votre Admin Shopify
2. Allez dans **Ventes en ligne** → **Thèmes**

### Étape 3 : Importer le thème
1. Cliquez sur **Ajouter un thème**
2. Cliquez sur **Importer un fichier ZIP**
3. Sélectionnez le dossier `lissia-shopify-theme-halal.zip`
4. Cliquez sur **Charger le fichier**

### Étape 4 : Activer le thème
1. Une fois le thème importé, cliquez sur **Personnaliser**
2. Configurez votre boutique (logo, couleurs, etc.)
3. Cliquez sur **Publier**

## 🎨 Configurabilité

Le thème propose de nombreuses options personnalisables :

- Couleur primaire (noir)
- Couleur accent (or)
- Polices (Inter)
- Largeur de page
- Espacement des sections
- Hauteur du héros

## 📋 Sections disponibles

1. **Héros** : Bannière de présentation
2. **Produits en vedette** : Affichage des produits
3. **Produit** : Page détail d'un produit
4. **Panier** : Gestion du panier

## 💡 Conseils d'utilisation

### Ajouter vos produits
1. Allez dans **Produits**
2. Cliquez sur **Ajouter un produit**
3. Remplissez les informations
4. Cliquez sur **Enregistrer**

### Ajouter votre logo
1. Allez dans la section **Thème** → **Personnaliser**
2. Cliquez sur **Logo**
3. Téléchargez votre image

### Personnaliser les couleurs
1. Dans **Personnaliser**
2. Allez dans **Couleurs**
3. Modifiez les couleurs primaire et accent
